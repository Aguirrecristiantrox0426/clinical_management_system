# clinical_management_system

Sistema web para la gestión y administración de información clínica.

## Descripción

Sistema de Gestión de Clínica desarrollado como proyecto académico del programa Análisis y Desarrollo de Software del SENA.

El sistema permite gestionar pacientes, médicos, disponibilidad, citas y atenciones médicas, además de usuarios, roles, notificaciones y reportes.
